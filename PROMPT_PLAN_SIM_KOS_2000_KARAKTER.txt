Buat PRD dan plan implementasi SIM Kos untuk TA Praktikum Sistem Informasi, siap dikerjakan AI di Google Antigravity. Bahasa Indonesia; buat rencana, bukan kode. Target: aplikasi nyata dengan database, demo lokal Windows.

Stack: Laravel, Blade, MySQL, Bootstrap 5, Chart.js; monolit, autentikasi session, migration/seeder, aset lokal, cetak/Save as PDF. Cek kompatibilitas versi.

Konteks Modul 1-3: satu usaha kos; masalah pendataan kamar/penghuni, pembayaran, fasilitas, keluhan, dan rekap pendapatan. Role: admin mengelola operasional; pemilik memantau dashboard/laporan; penghuni melihat pembayaran dan keluhan sendiri. Otorisasi wajib di server.

Alur:
1. Admin memeriksa penghuni/kamar. Jika tersedia, simpan penempatan dan ubah kamar menjadi terisi; jika tidak, tunda.
2. Penghuni membayar; admin memeriksa tarif, jumlah, periode. Jika sesuai, catat pembayaran/status/riwayat; jika tidak, informasikan koreksi, jangan anggap lunas.
3. Penghuni mengeluh; admin memeriksa, menindaklanjuti atau menutup dengan alasan; penghuni memantau status.

Wajib TA:
- Login/logout, akses berbeda.
- Master Kamar, Penghuni, Fasilitas: tambah, daftar, edit, hapus, cari, detail, validasi.
- Transaksi lintas tabel.
- Dashboard database: minimal 3 KPI, 2 grafik, 1 tabel.
- Dua laporan: pendapatan dan status pembayaran; filter periode, cari, urutkan, rekap, cetak.
- Audit: pengguna, aktivitas, modul, data, waktu.
- PK/FK, relasi, data contoh; UI responsif, notifikasi.

Asumsi: sewa bulanan penuh, satu penghuni aktif/kamar. Rancang tagihan agar belum bayar terdeteksi; snapshot tarif, cegah duplikasi, transaksi atomik, jaga histori saat hapus.

Output: PRD, matriks kebutuhan, ERD/data dictionary, spesifikasi fitur, task berdependensi dengan acceptance criteria/tes, prompt per tahap Antigravity, panduan Windows, test case, demo, dokumentasi, SQL dan GitHub. Bedakan fakta/asumsi. Tanpa payment gateway. Sertakan pembagian dua anggota dan penjelasan untuk presentasi.
